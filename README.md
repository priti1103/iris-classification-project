# Iris Classification Project

## Overview
This project performs machine learning classification using the Iris dataset.

## Algorithms Used
- Logistic Regression
- Decision Tree Classifier

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Dataset
Iris Dataset

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Results
Both Logistic Regression and Decision Tree models were trained and evaluated on the Iris dataset. Model performance was compared using classification metrics and confusion matrices.
